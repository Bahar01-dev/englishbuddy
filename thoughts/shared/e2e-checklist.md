## 4. Урок: 4 фазы, силлабус, элицитация (FR-03, FR-05, FR-13, FR-14, 5.3–5.5)

- ☐ **UI**: «Начать новый урок» → создаётся сессия, открывается `/lesson/[id]`, репетитор начинает сам (первый ход без ручного ввода).
- ☐ **БД** `lesson_sessions`: у новой строки `status='in_progress'` и **заполнен `syllabus_unit_id`** (выбран на старте).
- ☐ **Бейдж фазы** меняется по ходу: review → explanation → practice → summary (через tool use, без текстовых маркеров `PHASE:` в чате).
- ☐ **Presentation**: тема соответствует выбранному юниту (релевантна цели/уровню), объяснение с учётом L1/L2 (A1–A2 — больше русского).
- ☐ **Practice (элицитация)**: при ошибке ученика репетитор СНАЧАЛА мягко сигналит и даёт шанс переформулировать, и только после 2-й неудачи даёт правильный вариант (recast). Не использует слова «ошибка/неправильно».
- ☐ **Не-повтор тем**: пройди 2 урока подряд — темы (scenario_title) разные.
- ☐ **Safety-net**: кнопка «Завершить урок» доводит урок до конца, даже если модель не вызвала `complete_lesson`.
- ☐ Длинные ответы не обрываются (max_tokens 2048).

## 8. Streak — правила серии (FR-30)

> Дата считается по UTC; для проверки правил удобно править `last_active_date` в SQL Editor.

- ☐ **Первый урок**: `streak_count` стал 1, `last_active_date` = сегодня.
- ☐ **Второй урок в тот же день**: `streak_count` НЕ задваивается (остался прежним).
- ☐ **Продолжение**: выставь `last_active_date = вчера`, заверши урок → `streak_count += 1`, бейдж на дашборде растёт.
  ```sql
  update profiles set last_active_date = current_date - 1 where user_id = '<UID>';
  ```
- ☐ **Разрыв**: выставь `last_active_date = current_date - 2`, заверши урок → `streak_count` сброшен в 1, но `longest_streak` сохранил рекорд.
